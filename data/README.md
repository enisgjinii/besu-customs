# Data Directory

This folder stores non-runtime data assets used for imports, exports, references, and tooling.

## Structure

- `csv/imports/configurator/`: Configurator import CSVs
- `csv/imports/shopify/`: Shopify import CSVs
- `csv/references/`: Lookup/reference CSVs
- `csv/inventory/`: Inventory import CSVs
- `csv/checkout/`: Checkout-product CSVs
- `csv/exports/`: Export CSVs
- `json/maps/`: Rename and mesh-part mapping JSON files
- `json/generated/`: Generated JSON artifacts
- `json/summaries/`: Import/output summary JSON files
- `shopify/`: Shopify Liquid artifacts
