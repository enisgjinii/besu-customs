# How to Use the Decal System

## Quick Start

1. **Open the app** at http://localhost:3002

2. **Select a product** from the product list

3. **Switch to Texture tab** in the sidebar

4. **Create your decal:**
   - Add text by typing and clicking the "T" button
   - OR add an image by clicking "Add Image"
   - Customize colors, fonts, sizes

5. **Apply to model:**
   - Click "Apply Decal to Model"
   - Your texture will instantly appear on the 3D model

6. **Add more decals:**
   - Create new designs on the canvas
   - Apply multiple decals to build your design

7. **Clear all decals:**
   - Click "Clear All Decals" button

## Features

- **Text editing:** Change fonts, sizes, colors
- **Image upload:** Add logos or graphics
- **Canvas editing:** Move, resize, rotate objects on canvas
- **Delete selected:** Remove individual canvas objects
- **Download texture:** Save your design as PNG
- **Multiple decals:** Layer multiple designs on the model

## Tips

- The decal will project onto the front of the model by default
- You can apply the same design multiple times
- Use "Clear Canvas" to start fresh without removing applied decals
- Use "Clear All Decals" to remove all decals from the 3D model

## Current Limitations

- Decal position is fixed (front of model)
- Scale is set to 0.5x0.5x0.5
- No interactive placement yet
